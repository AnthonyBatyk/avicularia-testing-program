# Встановлення Avicularia Testing v245

1. Перед оновленням збережіть JSON КБЖВ і ZIP тренувань.
2. Розпакуйте вміст теки AVICULARIA_SITE_v245_TESTING у тестовий GitHub Pages-репозиторій.
3. Worker v110 і D1 залишаються без змін. Кеш Safari та IndexedDB не очищати.
4. Відкрийте повноекранне фото та перевірте при 100%, збільшенні +, зменшенні −, пересуванні пальцем і pinch-to-zoom: кути повинні лишатися заокругленими.
5. Перевірте закриття перегляду, повернення до додавання продукту та номер v245 у Консолі.

Основний сайт не змінювати без тестування на iPhone.

## Швидка перевірка v245

«Зручності» → «Вуглеводи без цукрів»: у порожніх полях «Вуглеводи, г» та «Цукри, г» видно `###` замість чисел. Після введення власних значень формула та кнопки працюють як раніше. Перед публікацією переконайтеся, що адреса API відповідає саме цьому середовищу. Не очищайте IndexedDB, Safari або D1. Worker v110 не змінювати.

## Правка v245
Швидкі ваги спрацьовують з першого дотику при фокусі поля на iOS. Розбір «Білки: 12,5» та інших семи показників у формі назва: значення. Сама кнопка «До калькулятора» лише додає текст до поля; для внесення у підсумок натисніть «Додати» в Калькуляторі. Worker v110 лишається без змін. Перед випуском на основний сайт зробіть резервний JSON КБЖВ; кеш не очищуйте.
